FAQ

Short answers. The other pages give the detail.

Is Quarterdeck a hosted service?

No. It runs on your own machine. The dashboard listens on loopback only.

What does it collect?

It never collects keystrokes, screen contents, which apps or websites you use, the clipboard, your location, or files outside the projects you register and its own data folder. Your run history, notes and settings stay in that folder on your machine.

Does it send my code anywhere?

To the model you already use, through the claude command on your machine, for the requests you ask for, on your own account and limits. It also talks to GitHub through gh for pull requests and issues, and to any service you connect yourself. Installing a project's dependencies uses the network.

Can an agent change my repository by itself?

Not on its own. By default agents only report. Builder agents can edit files inside a throwaway working copy, but the harness alone commits, pushes or posts, and only when you pass --apply or click.

Which systems does it run on?

macOS is the tested system. Linux is next: the Linux sandbox has run in CI only and is listed as unverified.

Are the cloud packs safe to rely on?

They are experimental and were tested on small examples only. Read an infra report as a second opinion, not a verdict.

Has it had a security review?

Not by a specialist yet. See the Security page for what has been tested and what has not.

Can I try it without connecting anything?

Yes. The Demo switch in the dashboard fills it with invented data.

Where is my data kept?

In ~/.quarterdeck by default, apart from the program. You can update or delete the program without touching it.

How do I report a security problem?

Use GitHub's private vulnerability reporting on the repository. Please do not open a public issue.

What licence is it under?

The Apache License 2.0.
