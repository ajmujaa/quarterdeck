# Code of conduct

Quarterdeck is a calm tool, and this is a calm project. Whoever you are, and however much experience you have, you are welcome here.

## What we ask

- Be kind and patient. Assume the other person is trying to help.
- Disagree about the work, not about the person. Say what you think is wrong and why.
- Keep it on topic and keep it plain. No harassment, insults, personal attacks, or unwelcome comments about anyone's identity.
- Do not share anyone's private information, such as an address, a credential or a private message, without their permission.
- Ask before you assume. A question is always welcome.

## Where this applies

Issues, pull requests, discussions, commit messages, and any other space where the project is discussed in public.

## When something goes wrong

If someone is not following this, say so politely once. If it continues, or if you would rather not say it in public, report it privately: open a private security advisory on this repository (the Security tab, then Report a vulnerability) and write "conduct" in the title, or contact the maintainer, @ajmujaa, through GitHub. Reports are read by the maintainer and kept private.

The maintainer may edit or remove comments, close issues and pull requests, or block a person from the repository when this is not followed. They will say why.

## Where this comes from

This is a short, plain version in the spirit of the Contributor Covenant (https://www.contributor-covenant.org).
