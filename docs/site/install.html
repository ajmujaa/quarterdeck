Install on macOS

There is no installer. You clone the program, make a data folder, and ask doctor what is missing.

You need

  • macOS (the tested system), with Python 3.10 or newer, bash and git.
  • jq, for example brew install jq.
  • The GitHub CLI, signed in: brew install gh, then gh auth login.
  • Claude Code, signed in: the claude command must work in a terminal.
  • Optional: Node 20 or newer, which runs the page-logic tests. Without it those tests are skipped.

Linux is also supported in principle, but its sandbox has run in CI only. See Security before relying on it.

Then

git clone https://github.com/ajmujaa/quarterdeck.git
cd quarterdeck
bin/qtdeck home init     # makes ~/.quarterdeck, your data folder
bin/qtdeck doctor        # checks the wiring and says what is missing

doctor lists each problem in plain words. Fix what it names and run it again until it is quiet. Nothing is placed outside the program folder, your data folder and the private file where credentials you enter are kept.

Connect Claude Code

Quarterdeck has no login of its own. It runs the claude command already on your machine, as you. Every model call uses your own account and your own usage limits. Read the provider's terms for automated use before you schedule many runs.

First run

bin/qtdeck dashboard

This starts the dashboard and opens a one-time pairing link to http://127.0.0.1:7878. The link is good for five minutes and works once. The Demo switch fills the dashboard with invented data so you can look around before you connect anything.

Attach a project

bin/qtdeck attach ~/Projects/my-app            # shows what it found; changes nothing
bin/qtdeck attach ~/Projects/my-app --apply    # registers it
bin/qtdeck run my-app surveyor --pr 12         # reports only
bin/qtdeck run my-app surveyor --pr 12 --apply # posts the review

Attach only folders you trust: the crew reads their files and the harness runs their test and build commands.
