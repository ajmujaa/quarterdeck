WHAT IT DOES

From an issue to a reviewed pull request

REVIEW
Reviews that know why
Reviewers get the decision records that cover the files in a change, and push back on a conflict.
BUILD
A crew with roles
One agent builds, one reviews, one checks security. Builders work in a throwaway copy of your repo.
RECORD
Decision records
Suggests decisions for a project that has none, and flags records the code has moved past.
MAP
The Brain
One map of your projects, agents and connected services. Each run shows which files it changed.
LIMITS
Spend caps
Daily and per-run limits, on your plan or an API key you choose.
LOCAL
Stays on your machine
The dashboard listens on loopback only and pairs with a one-time link.
CONNECT
Read-only connections
Each service shows what it reads, what it never reads and when it last refreshed.
GUARDRAILS
Rules the model can't edit
The harness checks, writes and posts. The model only returns data.
WHAT IS STILL MISSING

Quarterdeck is young. It has been run hard on one person's projects, built and used daily on macOS. The Linux sandbox is tested in CI only. Read SECURITY.md before you trust it with anything you care about.
