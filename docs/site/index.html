A calm control room for AI software-development agents

Quarterdeck runs on your own machine. It gives you one dashboard for all your projects and a built-in crew of agents that take work from an issue to a reviewed pull request. Nothing leaves your computer except the requests you ask for.

Install on macOS What is tested and what is not

Status: early. It is built and used daily on macOS. Linux is next. Expect rough edges, and read what is tested and what is not before you trust it with anything you care about.

What it is

A command, qtdeck, and a dashboard that listens on your machine only. You register a project (a repository). The crew, which are short markdown files each describing one point of view, can then review pull requests, write issues, plan a sprint, fix a bug or take one issue to a pull request. You read the result and decide.

The one rule

The model thinks, the harness acts. No agent is given credentials or write tools. An agent reads, reasons and ends its reply with a machine-readable contract. A script parses the contract and does the privileged thing (posts a comment, opens a branch, files an issue), and only with an explicit --apply. A reply that does not parse is a failed run that writes nothing.

What it never collects

  • Keystrokes
  • Screenshots or screen contents
  • Which apps or websites you use
  • The clipboard
  • Your location
  • Any file outside the projects you register and its own data folder

A test scans the code for the programming interfaces that would do any of this. Read how it stays safe.
